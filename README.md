## Как запустить

Нужен только Docker: .NET SDK и Node.js устанавливать не требуется — всё
собирается внутри контейнеров.

```bash
# 1. Склонировать репозиторий
git clone https://github.com/waleron07/timesheet-test-task.git
cd timesheet-test-task

# 2. Поднять всё одной командой (первый запуск — несколько минут на сборку)
docker compose up --build

# 3. Наполнить базу приёмочными данными           ← появится на этапе 2
docker compose exec api dotnet Timesheet.Api.dll seed

# 4. Открыть интерфейс
open http://localhost:5173

# 5. При необходимости — Swagger для ручных запросов
open http://localhost:8080/swagger
```

| Сервис | Адрес |
|---|---|
| Фронтенд | http://localhost:5173 |
| API | http://localhost:8080 |
| Swagger | http://localhost:8080/swagger |
| Healthcheck | http://localhost:8080/api/health |
| MongoDB | localhost:27017, база `timesheet` |

`/api/health` проверяет не только то, что процесс API поднялся, но и что
MongoDB отвечает на `ping`.

### Тестовые данные

Команда сида **идемпотентна и сносящая**: очищает коллекции и заливает ровно
приёмочный набор из задания — 2 сотрудника, 2 проекта, 4 записи табеля.

Это существенно при проверке. Сценарии с ошибками из задания создают в базе
лишние записи (в частности, 20 часов Иванову на 06.03.2026 сохраняются
успешно — так и задумано), после чего отчёт за март покажет 32 часа вместо
ожидаемых 12 по П-001. Порядок проверки:

```
seed → сверить отчёты → прогнать сценарии с ошибками → seed заново
```

### Тесты

```bash
docker run --rm -v "$PWD":/src -w /src mcr.microsoft.com/dotnet/sdk:8.0 \
  dotnet test Timesheet.sln
```

Сейчас: **53 теста**, все зелёные. Пять обязательных по ТЗ лежат в файлах с
говорящими именами:

| Правило из ТЗ | Файл |
|---|---|
| выбор ставки по дате | `RateSelectionTests.cs` |
| лимит часов за день | `DailyHoursLimitTests.cs` |
| закрытый период | `ClosedPeriodTests.cs` |
| границы периода проекта | `ProjectPeriodTests.cs` |
| округление денег | `MoneyRoundingTests.cs` |

Дополнительно `HoursValidationTests`, `OvertimeTests` и
`AcceptanceFiguresTests` — последний пересчитывает все цифры из раздела
«Приёмочные проверки» задания.

### Полезные команды

```bash
docker compose up -d --build     # пересобрать после изменений в коде
docker compose logs -f api       # логи API
docker compose down              # остановить
docker compose down -v           # остановить и стереть данные MongoDB
```

## Структура

```
├── src/
│   ├── Timesheet.Domain/      сущности и бизнес-правила
│   │                          без зависимостей на MongoDB и ASP.NET
│   └── Timesheet.Api/         контроллеры, обработчики, доступ к MongoDB
├── tests/Timesheet.Tests/     юнит-тесты бизнес-правил
├── web/                       React 18 + TypeScript + Vite
├── code-review/               часть 1: исходные файлы и исправленные версии
└── docker-compose.yml
```

Домен намеренно не знает ни про MongoDB, ни про HTTP: бизнес-правила должны
проверяться без поднятой базы. Подробнее — в [`NOTES.md`](NOTES.md).
